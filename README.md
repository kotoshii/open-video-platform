# Open Video Platform

Inspired by [Open Streaming Platform](https://github.com/Open-Streaming-Platform/open-streaming-platform)

> [!WARNING]  
> The project is still on early stages of development!
> The current state of the codebase should be viewed as a "demo" of what is planned, as it lacks some critical security measures and some important features:
> * Kafka brokers do not have any authentication.
> * gRPC requests do not have any authorization.
> * Video uploading and processing flow is in progress.
> * Recommendation system is missing.
> * Search system is missing.
