## Set up Vitest for the UI

Needs: [frontend Task-01 — Create the Next.js app](../frontend/Task-01-Create-the-Nextjs-app.md)

Set up Vitest for the Next.js app, with jsdom, React Testing Library and the app's path aliases, and add a `test`
script.

Why: Vitest runs TypeScript and JSX through Vite with next to no config, which is why the Next.js docs suggest it for
unit tests.
