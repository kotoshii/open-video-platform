## Open the sidebar as a drawer on mobile

Needs: [Task-02 — Build the sidebar navigation](Task-02-Build-the-sidebar-navigation.md)

Main flow:

1. User taps the menu button.
2. The sidebar opens as a full-screen drawer, with a back arrow next to the logo at the top.
3. Tapping an item opens its page and closes the drawer.
4. The back arrow closes the drawer without navigating.

The page behind the drawer does not scroll while it is open.

Why: the drawer renders the same sidebar as the desktop one, so an item added once appears in both.
